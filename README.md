# Telegram Football Bot ⚽🤖
Developed by: Mazin Hijran Ibrahim

An interactive Telegram bot built with Python that fetches schedules for top European football leagues (Champions League, Premier League, La Liga, etc.), translates team names and competitions into Arabic, and provides an interactive inline menu.

## Tech Stack:
- **Python**
- **Python-Telegram-Bot API**
- **Football-Data.org API**
